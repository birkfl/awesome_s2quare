# Tagging guide

Add papers to the `paper` collection in the `awesome_s2quare` Zotero group.

Use ordinary Zotero tags for topics. Each topic tag becomes a section in the
generated list. Tags are normalized for display, so `qMRI` and `qmri` are shown
as the same topic.

Special tags:

- `featured` puts a paper in the featured section.
- `must-read` marks a paper as especially recommended.

Avoid tags that contain private notes or sensitive information. The group is
publicly readable and metadata is published to this repository.
